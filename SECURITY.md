# Política de segurança

## Como reportar uma vulnerabilidade

**Não abra issues públicas para problemas de segurança.**

Use o recurso **[Report a vulnerability](https://docs.github.com/pt/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)** do GitHub. Ele fica na aba *Security* do repositório afetado. Só os mantenedores veem o relato.

Inclua no relato:

- o repositório e a rota ou tela afetada;
- os passos para reproduzir;
- o impacto esperado (vazamento de dados, escalonamento de permissão etc.).

## Prazos

| Etapa | Prazo |
| --- | --- |
| Confirmação de recebimento | até 3 dias úteis |
| Avaliação inicial | até 7 dias úteis |
| Correção de falhas críticas | o mais rápido possível, com aviso ao relator |
