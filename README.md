# T3OOH/.github

Arquivos padrão da organização **T3 OOH**. O GitHub os aplica automaticamente a todos os repositórios que não tiverem uma versão própria.

| Arquivo | Função |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Página da organização em github.com/T3OOH |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Fluxo de branches, commits e Pull Requests |
| [`SECURITY.md`](SECURITY.md) | Como reportar vulnerabilidades |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Modelo de descrição de PR |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Formulários de bug e melhoria |
